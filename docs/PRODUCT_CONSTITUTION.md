# Product Constitution — NotTheLeast

*Immutable source of truth. Amendments require explicit owner instruction.*

---

## 1. Product Identity

NotTheLeast is a developer operating layer that abstracts codebases, knowledge, tasks, dependencies, agents and execution.

## 2. Core Design Decisions

### 2.1 Deterministic abstraction layer

The abstraction and control layer must be deterministic and reproducible.

### 2.2 Intent definition

NotTheLeast defines **what** must happen: intent, objectives, constraints, dependencies, permissions and acceptance criteria.

### 2.3 Execution autonomy

The execution layer may use agents extensively and autonomously decides **how** to accomplish the defined objective.

### 2.4 Agent boundaries

Agents cannot silently redefine objectives, priorities, constraints or acceptance criteria.

### 2.5 Nondeterministic implementations

Final implementations may be nondeterministic, provided they satisfy the defined contract.

### 2.6 Distinguishable information

Facts, assumptions, inferences, decisions and verified results must remain distinguishable.

### 2.7 Agent role constraints

Agents are execution components, never the authority on project truth.

### 2.8 User and system roles

The user manages intent and outcomes; NotTheLeast manages work, knowledge and control flow.
